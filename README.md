# mediaInspector - Инспектор мультимедийных файлов

Легковесное приложение на C++ для сканирования директории и отслеживания мультимедийных файлов (аудио, видео, изображения) с предоставлением результатов через HTTP API.

## Возможности

- Рекурсивное сканирование директории
- Поддержка форматов:
  - **Аудио**: mp3, wav, flac, ogg, m4a, aac, wma
  - **Видео**: mp4, avi, mkv, mov, wmv, flv, webm, mpeg, mpg
  - **Изображения**: jpg, jpeg, png, gif, bmp, tiff, webp, svg
- Фоновое периодическое сканирование (настраиваемый интервал)
- HTTP REST API endpoint `/media_files`
- Настраиваемые параметры: директория сканирования, порт, интервал

## Требования

- **Операционная система**: Linux
- **Компилятор**: GCC 7+ или Clang 5+ с поддержкой C++17
- **Система сборки**: CMake 3.10+
- **Зависимости**: pthread, STL

## Сборка

```bash
# Клонирование репозитория
git clone <repository-url>
cd fileInspector

# Создание директории для сборки
mkdir build && cd build

# Конфигурация CMake
cmake ..

# Сборка
make

# Запуск (пример)
./fileInspector -d /путь/к/директории -p 8080
```

## Использование

### Аргументы командной строки

| Опция | Описание | Значение по умолчанию |
|-------|----------|----------------------|
| `-d директория` | Путь для сканирования | Домашняя директория (`$HOME`) |
| `-t интервал_сек` | Интервал сканирования в секундах | 5 |
| `-p порт` | Порт HTTP-сервера | 8080 |
| `-h` | Показать справку | - |

### Примеры запуска

```bash
# Сканирование домашней директории с интервалом 5 секунд на порту 8080
./fileInspector

# Сканирование указанной директории с интервалом 10 секунд
./fileInspector -d /home/user/Music -t 10

# Сканирование с пользовательским портом
./fileInspector -d /home/user/Videos -p 3000

# Полный набор параметров
./fileInspector -d /media/data -t 30 -p 9090

# Показать справку
./fileInspector -h
```

### HTTP API

После запуска сервера результаты сканирования доступны по адресу:

```
http://localhost:8080/media_files
```

#### Пример ответа

```json
{
  "audio": ["song1.mp3", "song2.wav", "podcast.ogg"],
  "video": ["movie.mp4", "clip.avi"],
  "images": ["photo.jpg", "screenshot.png"]
}
```

## Архитектура

```
fileInspector
├── main.cpp                 # Точка входа, разбор аргументов
├── src/
│   ├── Inspector.hpp/cpp    # Сканирование файловой системы (nftw)
│   └── Server.hpp/cpp       # HTTP-сервер (cpp-httplib)
├── lib/
│   ├── cJSON/               # Генерация JSON
│   └── cpp-httplib/         # HTTP-библиотека
└── CMakeLists.txt           # Конфигурация сборки
```

### Потоки выполнения

1. **Основной поток**: Запускает HTTP-сервер и ожидает сигнала остановки
2. **Фоновый поток Inspector**: Периодически сканирует директорию с помощью `nftw()`

### Оптимизация данных

- Временные векторы заполняются без блокировок во время сканирования
- Атомарный `swap` под мьютексом после завершения сканирования (O(1))
- JSON формируется из актуальных данных под защитой мьютекса

## Остановка сервера

Нажмите `Ctrl+C` в терминале. Приложение выполнит корректное завершение всех потоков.
